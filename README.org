* Overview

=.sbcl.d= is a modular, extensible SBCL configuration system inspired by Spacemacs. It provides a layer-based approach to configuring SBCL, making it easy to organize, extend, and maintain your Common Lisp development environment.

** Features

- 🎯 *Modular Layer System* - Organize configuration into logical, reusable layers
- 🚀 *Rich REPL Experience* - Enhanced REPL with utilities, history, and helpers
- 🔧 *Development Tools* - Profiling, debugging, code inspection, and analysis
- 📦 *Project Management* - Seamless Quicklisp integration and project scaffolding
- 📚 *Comprehensive Help* - Built-in documentation and learning utilities
- ⚙️  *Easy Customization* - Simple user configuration without modifying core files
- 🎨 *Spacemacs-Inspired* - Familiar concepts for Emacs users

* Installation

** Quick Install

Clone the repository:

#+begin_src sh
git clone <repository-url> ~/.sbcl.d
cd ~/.sbcl.d
make init
#+end_src

This will:
1. Backup your existing =~/.sbclrc= (if it exists)
2. Create a symlink to =~/.sbcl.d/.sbclrc=
3. Set up the =local-projects= directory

** Manual Install

#+begin_src sh
git clone <repository-url> ~/.sbcl.d
ln -sf ~/.sbcl.d/.sbclrc ~/.sbclrc
#+end_src

* Layers

The configuration system is organized into four main layers:

** Core Layer (=:core=)

Essential utilities and REPL enhancements.

*** Features:
- String and collection utilities (=str=, =join=, =split=)
- File system operations (=pwd=, =cd=, =ls=, =mkdir=)
- System utilities (=getenv=, =setenv=, =shell=)
- Timing and benchmarking (=benchmark=, =with-timing=)
- Pretty printing (=pp=, =pph=)
- REPL history
- Package and symbol inspection
- Common aliases

*** Example Usage:
#+begin_src lisp
;; String operations
(str "Hello" " " "World" "!" 123)  ; => "Hello World!123"
(join ", " '("apple" "banana" "cherry"))  ; => "apple, banana, cherry"
(split "one,two,three" #\,)  ; => ("one" "two" "three")

;; File operations
(pwd)                    ; Print working directory
(cd "/tmp")             ; Change directory
(ls)                    ; List files
(mkdir "/tmp/test")     ; Create directory

;; Benchmarking
(benchmark (:times 1000)
  (+ 1 2 3))

;; Timing a single operation
(with-timing
  (sleep 1))

;; Package inspection
(packages)              ; List all packages
(exports :cl)           ; List exported symbols from CL
(functions :cl-user)    ; List all functions in CL-USER
#+end_src

** Development Layer (=:dev=)

Debugging, profiling, and code inspection tools.

*** Features:
- Object inspection (=inspect-object=, =what-is=)
- Code navigation (=source=, =who-calls=, =who-references=)
- Profiling tools (=profile-function=, =profile-report=)
- Memory management (=memory-info=, =gc=)
- Debug mode (=debug-on=, =debug-off=)
- Testing helpers (=assert-equal=, =test-group=)
- Code quality checks (=check-style=)

*** Example Usage:
#+begin_src lisp
;; Inspect a symbol - see EVERYTHING about it
(what-is 'mapcar)

;; Find who calls a function
(who-calls 'my-function)

;; Profile code
(profile-function 'expensive-function)
(expensive-function)
(profile-report)
(unprofile-all)

;; Memory information
(memory-info)
(gc)  ; Force garbage collection and show stats

;; Debug mode (unlimited print depth/length)
(debug-on)
(debug-off)

;; Simple testing
(test-group "Math tests"
  (assert-equal 4 (+ 2 2) "Addition")
  (assert-equal 10 (* 5 2) "Multiplication")
  (assert-true (> 5 3) "Comparison"))
#+end_src

** Project Layer (=:project=)

Project creation, management, and Quicklisp integration.

*** Features:
- Project creation (=new-project=, =scaffold-project=)
- Project management (=local-projects=, =open-project=)
- ASDF system utilities (=systems=, =system-info=)
- Quicklisp helpers (=ql=, =qls=, =update-quicklisp=)
- Workspace management (=save-workspace=, =load-workspace=)

*** Example Usage:
#+begin_src lisp
;; Create a new project with dependencies
(new-project "my-app" :alexandria :cl-ppcre)

;; Create a fully scaffolded project (better!)
(scaffold-project "web-app"
  :author "Your Name"
  :license "MIT")

;; Quick load a system
(ql :hunchentoot)

;; Search Quicklisp
(qls "http")

;; List local projects
(local-projects)

;; Open and load a project
(open-project "my-app")

;; Get info about a system
(system-info :alexandria)

;; Workspace management - save your current state
(save-workspace "web-dev")

;; Later, restore everything
(load-workspace "web-dev")
#+end_src

** Documentation Layer (=:docs=)

Help system, documentation search, and learning utilities.

*** Features:
- Comprehensive help system (=help=)
- Enhanced documentation (=doc=, =search-doc=)
- Improved apropos (=apropos-full=)
- Example system (=examples=, =add-example=)
- Quick reference (=quickref=)

*** Example Usage:
#+begin_src lisp
;; Get help
(help)                      ; Show overview
(help :layers)             ; Help on layers system
(help :config)             ; Help on configuration
(help :quicklisp)          ; Help on Quicklisp
(help :profiling)          ; Help on profiling

;; Documentation
(doc 'mapcar)              ; Show all documentation
(search-doc "iterate")     ; Search in documentation

;; Enhanced apropos - categorized by type
(apropos-full "map")       ; Shows functions, macros, variables separately

;; Quick reference for Common Lisp
(quickref)                 ; Show categories
(quickref :lists)          ; List operations
(quickref :strings)        ; String operations
(quickref :hash)           ; Hash table operations

;; Examples (you can add your own!)
(examples 'mapcar)
(add-example 'my-function "(my-function 1 2 3) => 6")
#+end_src

** Workflow 3: Debugging Performance Issues

#+begin_src lisp
;; 1. Enable debug mode for more info
(debug-on)

;; 2. Check initial memory
(memory-info)

;; 3. Profile the slow function
(profile-function 'slow-function)
(profile-function 'helper-function-1)
(profile-function 'helper-function-2)

;; 4. Run your code
(slow-function big-data)

;; 5. See the report

;; 6. Clean up
(unprofile-all)
(gc)
(memory-info)  ; Compare with before
#+end_src

** Creating Custom Layers

Create =~/.sbcl.d/layers/my-layer.lisp=:

#+begin_src lisp
;;;; my-layer.lisp - Custom Layer

(in-package #:cl-user)

;; Your custom functions
(defun quick-test ()
  "Run quick tests"
  (format t "Running tests...~%")
  ;; Your test code here
  )

* Troubleshooting

** Configuration not loading

Check that =~/.sbclrc= points to =~/.sbcl.d/.sbclrc=:

#+begin_src sh
ls -la ~/.sbclrc
# Should show: .sbclrc -> /home/you/.sbcl.d/.sbclrc
#+end_src

** Quicklisp not found

Ensure Quicklisp is installed at =~/quicklisp/=:

#+begin_src sh
ls ~/quicklisp/setup.lisp
#+end_src

If not, install Quicklisp:
#+begin_src sh
curl -O https://beta.quicklisp.org/quicklisp.lisp
sbcl --load quicklisp.lisp --eval '(quicklisp-quickstart:install)'
#+end_src

** Layer not loading

Check layer exists and has no syntax errors:

#+begin_src sh
sbcl --script ~/.sbcl.d/layers/core.lisp
#+end_src

** User config not loading

Make sure it's named correctly:
#+begin_src sh
ls ~/.sbcl.d/user-config.lisp  # NOT user-config.lisp.example
#+end_src

** Function not found

Check which layers are loaded:
#+begin_src lisp
sbcl-config:*loaded-layers*
#+end_src

** Symbols in wrong package

Remember that layer functions are in =CL-USER= by default:
#+begin_src lisp
;; This works:
(help)

;; This also works:
(cl-user::help)

;; But configuration functions are in SBCL-CONFIG:
(sbcl-config:reload-config)
#+end_src

#+begin_src lisp

  (cl-csv:read-csv #p"~/data/sales.csv"))

;; 3. Analyze

  (/ (reduce #'+ (mapcar #'parse-number
                         (mapcar #'second *data*)))
     (length *data*)))

  (average-sales))

(profile-function 'average-sales)
(average-sales)
(profile-report)
#+end_src
